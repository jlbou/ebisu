# Decision 6: el tiempo de dedicacion (12/10/2026)

## Decidido (opcion C)

- **Mientras se hace (estudio y, si pasa, el bot): sin ritmo fijo**, cuando el propietario pueda. Cada paso se deja preparado y se
  espera a su respuesta; no hay fechas que obliguen.
- **Cuando funcione: que el propietario no tenga que hacer nada** (decision 4). Como mucho, leer un resumen por Telegram.

## Lo que implica

- Cada entrega tiene que poder leerse sola, sin acordarse de la anterior: que se ha hecho, que sale y que decision
  falta, con la recomendada marcada.
- Nada avanza al paso siguiente sin el OK del propietario, aunque tarde.
- "No hacer nada" tiene un limite: si el bot se para o el broker cambia algo, llegara un aviso y el propietario tendra que decidir
  (poco a menudo, pero no nunca).
